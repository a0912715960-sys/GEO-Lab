# 五分钟产品操作演示

0:00–0:40 打开总览，先看“真实 API 记录”。未配置密钥时指标为零。说明用户是企业运营、外贸营销和商品运营；目标是将商品级 GEO 表现连到具体证据与内容动作。

0:40–1:20 进入商品与事实库，区分工业案例和公开硬件规格。导入 CSV，展示待审核事实、SKU 来源和冲突裁定。演示只有已审核且来源未撤回的事实能进入检索。

1:20–2:00 生成英语或德语采购问题，人工修改并批准。创建监测计划，展示冻结版本、模型、语言、频率、每日上限。说明实际配置密钥后由官方搜索 API 采样，本地服务关闭则停止调度。

2:00–3:00 点击“加载独立案例”，界面明确切换为案例数据。解释 N100 → B32 → R18；引用 C12 独立存在，R/B 为 56.25%。点击引用卡片，打开没有品牌提及但有域名引用的案例原文。此段展示计算与证据链，不展示真实增长。

3:00–4:15 从样本创建诊断，说明当前原因是待验证假设。生成参数/FAQ 修改，人工编辑一个片段，接受或拒绝各段。查看完整待批准 JSON，批准并导出，展示导出对象与批准快照相同。

4:15–5:00 打开复测实验室。真实基线不足时不创建虚假实验。配置真实 API 后，锁定采样条件和用户声明的上线时间；前后比较注明样本量、不可比条件与因果限制。最后展示实际测试报告和本机 API 配置说明。
